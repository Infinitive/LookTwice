# Publishing checklist

Before a piece goes live, check every item below:

- title is final
- summary is clear and complete
- status is set to `published`
- `published` date is present
- homepage flag is intentional
- `related` list is curated
- build passes locally
- content review is complete

Then run:

```bash
npm run check
npm run build
```

If the build passes and the piece reads clearly, it can go live.
