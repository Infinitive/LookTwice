# LookTwice V5

## Replace the repository

Copy the contents of this folder into the existing repository root. Do not place the LookTwice_V5 folder itself inside the repository.

The root must directly contain `src`, `public`, `.github`, `package.json`, `astro.config.mjs`, and `netlify.toml`.

`dist` is generated by Netlify and should not be committed.

## Local commands

```bash
npm install
npm run dev
npm run editorial
npm run build
```

- `npm run editorial` generates a private workflow dashboard at `.editorial/dashboard.html`.
- `npm run build` validates content, type-checks Astro, and builds the production site.

## Add content

Duplicate an existing Markdown file in `src/content/story`, `src/content/notes`, or `src/content/things` and change the fields and body.

See `docs/EDITORIAL-WORKFLOW.md`.
